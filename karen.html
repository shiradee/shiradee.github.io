Karen, with actions

A retail floor assistant that answers with UI when UI beats text. Same voice, tags and fixed rules as the chat version.

  • Stock card from the store system, never a guess
  • Size picker that applies the fit rule
  • Policy card with the allowed actions only
  • One-tap manager alert; never confront
  • Inter-store transfers when a size is out, started on confirmation
  • Price match from a live price on the customer’s phone
  • Store job openings with a QR code on the receipt
  • Quick replies so associates barely type

Concept by Shira Kates, built in Google AI Studio and extended with Claude. Inventory, prices, jobs and alerts are demo data.
